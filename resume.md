## Проекты

**Parser — сервис поиска коммерческой недвижимости** (выпускной проект курса, реальный заказчик — агентство недвижимости, СПб). Единый поиск по 5-10 площадкам, отсев по зонам клиента на карте, справка по окружению, Excel. AI-анализ описания: LLM возвращает 8 характеристик помещения с цитатами из текста, анализ дешевле рубля.

**4INS — AI-CRM страхового агента** (для собственной работы, на VPS). Клиенты и полисы всех страховых в одном окне, контроль продлений, сверка КВ по реестрам Excel/PDF. Четыре агента на CrewAI: парсинг правил страхования, ответы и сравнение условий компаний, база знаний. В работе: 272 клиента, 650 полисов.

**Интерактивное КП по ДМС.** Одностраничник с калькулятором вместо КП на 50 страниц: клиент выбирает клинику и опции и сразу видит цену. Тарифы — из Google Sheets через API, разворачивается под каждого клиента.

**Проекты курса:** SMM-эксперт с ИИ для ВКонтакте (посты, изображения, автопубликация, статистика); ИИ-ассистент для прескоринга кандидатов; кастдев и выделение ЛПР в Google Sheets с ChatGPT.
